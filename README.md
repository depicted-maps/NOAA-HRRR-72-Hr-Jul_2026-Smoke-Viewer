# NOAA HRRR 72-Hour Smoke Viewer

### Historical Wildfire Smoke Animation | July 15–17, 2026

An interactive, 72-hour visualization of modeled wildfire smoke concentrations across the contiguous United States and Rhode Island, using archived NOAA High-Resolution Rapid Refresh (HRRR-Smoke) model data.

The viewer presents 72 consecutive hourly analyses with synchronized national and Rhode Island displays, consistent concentration colors, and interactive playback controls.

### Features
- 72-hour historical smoke animation
- National and Rhode Island map coverage
- Play, pause, step-forward, and timeline controls
- Adjustable animation playback speed
- Synchronized UTC and Eastern Daylight Time displays
- Fixed smoke-concentration color scale
- Highlight of the peak modeled Rhode Island smoke concentration

### Historical Event

**Period:** July 15–17, 2026 (UTC)

**Peak Rhode Island statewide modeled mean:**
- July 16, 2026, at 6:00 PM EDT (22:00 UTC)
- 188.04 µg/m³

The peak represents the highest modeled statewide mean within the analyzed 72-hour period.

### Data Source

NOAA HRRR-Smoke archived model data, using near-surface smoke mass density (`MASSDEN`) at 8 meters above ground.

Concentrations are displayed in micrograms per cubic meter (µg/m³).

**Important:** These are modeled smoke concentrations, not measured ground-level PM2.5 concentrations or U.S. EPA Air Quality Index (AQI) values. Display colors are visualization classes, not EPA AQI categories.

### Purpose

This demonstration illustrates the geographic movement, concentration, and timing of a modeled wildfire smoke event over the northeastern United States, with particular attention to Rhode Island.

**Data provider:** NOAA  
**Visualization:** Independent GIS demonstration  
**Platform:** ArcGIS Pro and GitHub Pages

### Disclaimer

This historical visualization is intended for educational, demonstration, and GIS analysis purposes. It should not be used as a substitute for official air-quality observations, public health guidance, or operational smoke forecasts.
